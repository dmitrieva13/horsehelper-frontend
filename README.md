#  Веб-приложение дл конных школ (клиентская часть)
В данном репозитории представлена клиентская часть веб-приложения для конных школ. Приложение предоставляет обширный функционал для управления конно-спортивной школой с разделением доступа в зависимости от роли пользователя.

**Стек технологий:** 
* TypeScript
* React
* React Hooks
* CSS
* HTML
* Bootstrap

## Ролевая модель и функционал

### Неавторизованные пользователи
- Просмотр новостей
- Ознакомление с тренерским составом и лошадьми школы
- Регистрация в системе

### Ученики
- Онлайн запись на занятия с возможностью выбора направления, времени, тренера и лошади
- Отмена занятия онлайн 
- Просмотр архива тренировок
- Внутренние уведомления о предстоящем занятии

### Тренера 
- Настройка своего расписания
- Внутренние уведомления о новых и отмененных занятиях

### Администратор
- Добавление тренеров и лошадей в систему 
- Настройка рабочего графика лошадей
- Просмотр всех запланированных занятий
- Создание новостей

Все пользователи могут редактировать свой профиль.


## Установка
1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/dmitrieva13/horsehelper-frontend.git
    cd horsehelper-frontend
    ```
2. Установите Node.js с [официального сайта](https://nodejs.org/en/download)
3.  Установите необходимые библиотеки:
    ```bash
    npm install
    ```

## Запуск
1.  Запустите проект:
    ```bash
    npm start
    ```
2.  Проект запустится в браузере по ссылке `localhost:3000`

## Структура проекта
-   `src` - папка с кодом приложения
-   `src/style` - CSS-файлы с описанием внешнего вида приложения
-   `tsconfig.json` - инструкция для TypeScript
-   `webpack.config.cjs` - инструкция для сборки приложения
